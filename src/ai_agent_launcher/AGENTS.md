# AI agent launcher source guidance

For a durable decision limited to this tool's public contract, adapter
boundary, configuration model, or persisted launcher format, read
`../../docs/ai-agent-launcher/adr/README.md` and its relevant records before
changing source. Use the scoped records when the decision applies only to this
tool; use `../../docs/adr/README.md` only when the rule must govern multiple
independent tools in this repository.

When editing a scoped decision record, apply its nested `AGENTS.md` guidance
and reread the changed record and guidance before continuing.
